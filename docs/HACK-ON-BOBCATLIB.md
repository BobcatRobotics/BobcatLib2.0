# Hack on BobcatLib 🐱‍💻

Here are the steps you need to take to update bobcatlib.

1. Go to the `Vendordep` branch of the repo
2. Go to `src/main/java/BobcatLib` and make your changes there. 
> [!WARNING]  
> If your changes are not under the `src/` folder, they will get overriden! It is easy to accidentally change autogenerated classes in other folders, so make sure you don't do that.
3. Once your changes are made, go to `BobcatLib/BobcatLib.json` and increment both variables named `"version"` using the following format `x.x.x.x`
4. Go to `publish.gradle` and increment `pubVersion` here as well

> [!WARNING]  
> If you don't increment the version properly, or set it to a version that was already used, many things will break, so please don't do that 🙏🙏
5. Go to the terminal and run the update script. This will regenerate all of the autogenerated files to include your changes. On windows powershell, run `.\update.bat` on linux bash, run `./update.sh`
6. Go to the source control tab, and stage all your changes, then unstage `wpimath.pdb`, this file is too large for git to handle
7. Commit your changes!
